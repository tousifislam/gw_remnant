Citation
========

If you use ``gw_remnant`` or the ``BHPTNRremnant`` surrogate models in your
research, please cite the following paper:

.. code-block:: bibtex

   @article{Islam:2022laz,
       author = "Islam, Tousif and Field, Scott E. and Khanna, Gaurav.",
       title = "{Remnant black hole properties from numerical-relativity-informed
                 perturbation theory and implications for waveform modelling}",
       eprint = "https://arxiv.org/abs/2301.07215",
       archivePrefix = "arXiv",
       primaryClass = "gr-qc",
       month = "1",
       year = "2023"
   }

If you use any module from the Black Hole Perturbation Toolkit, please also
include the acknowledgement:

   *This work makes use of the Black Hole Perturbation Toolkit.*
